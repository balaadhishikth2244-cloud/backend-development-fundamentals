## Project Description
This project demonstrates a basic Node.js HTTP server and an Express server with GET routes and 404 error handling.

## Technologies Used
- Node.js
- Express.js
- JavaScript

## Installation
```bash
npm install
```

## Run the Express Server
```bash
npm start
```

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Welcome message |
| GET | `/about` | Returns name and section |
| GET | `/time` | Returns current date and time |
| GET | Unknown path | Returns a 404 error |
